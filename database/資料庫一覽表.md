# 資料庫一覽表

## 1. `users` (使用者表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **account** | VARCHAR(100) | PRIMARY KEY | 登入帳號 使用者唯一識別碼 只能是英文和數字 |
| **name** | VARCHAR(100) | NOT NULL | 使用者姓名 |
| **is_staff** | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否為社區工作人員（`TRUE`: 工作人員/里長/幹事，`FALSE`: 一般里民） |
| **staff_village** | VARCHAR(100) | NULL | 工作人員授權村里（工作人員必要，且僅能有一個；一般居民為 NULL）|



```sql
CONSTRAINT chk_account_alphanumeric CHECK (account ~ '^[A-Za-z0-9]+$'),
CONSTRAINT chk_staff_village_binding CHECK ((is_staff = TRUE AND staff_village IS NOT NULL AND staff_village <> '') OR (is_staff = FALSE AND staff_village IS NULL))
```

## 2. `categories` (申報類別字典表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 |
| --- | --- | --- | --- |
| **categories_id** | SERIAL | PRIMARY KEY | 唯一識別碼（PostgreSQL 自動遞增整數） |
| **key_name** | VARCHAR(50) | NOT NULL, UNIQUE | 程式用的英文 key (如: dengue) |
| **label** | VARCHAR(100) | NOT NULL | 前端顯示用的中文名稱 (如: 登革熱跡象申報) |
| **color_code** | VARCHAR(10) | NOT NULL | 前端標籤顏色代碼 (如: #FF4552) |
| **require_closing_image** | BOOLEAN NOT NULL | DEFAULT FALSE | 結案時是否強制要求上傳完工證明圖片（TRUE: 必填，FALSE: 選填）|

## 3. `cases` (通報案件表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **cases_id** | BIGINT | PRIMARY KEY | 案件編號 (例如：`1717000000011`) |
| **description** | TEXT | NOT NULL | 問題詳細描述 |
| **category_id** | INT | NOT NULL | 申報類別, 🔗 **外鍵**：對應 `categories.categories_id` |
| **images** | JSONB | NULL | 圖片陣列 (存放 GCS 網址或檔名陣列，採高效二進位 JSONB) |
| **status** | VARCHAR(50) | NOT NULL, DEFAULT 'pending' | 處理狀態 (例如：`pending`, `resolved`) |
| **created_at** | BIGINT | NOT NULL | 案件建立時間 (13位數毫秒時間戳) |
| **author_account** | VARCHAR(100) | NOT NULL | 發布者帳號, 🔗 **外鍵**：對應 `users.account` |
| **address** | TEXT | NOT NULL | 地址 |
| **reject_reason** | TEXT | NOT NULL | 案件被駁回的原因 |

## 4. `event_drafts` (事件草稿暫存表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **draft_id** | VARCHAR(64) | PRIMARY KEY | 草稿唯一識別碼 (例如: `draft_sample_001` 或 UUID) |
| **line_user_id** | VARCHAR(100) | NOT NULL | LINE 使用者唯一識別碼 (UID) |
| **author_account** | VARCHAR(100) | NULL | 綁定之系統帳號, 🔗 **外鍵**：對應 `users.account` (未綁定可為 NULL) |
| **category_id** | INTEGER | NULL | Agent 初步推論類別, 🔗 **外鍵**：對應 `categories.categories_id` |
| **status** | VARCHAR(50) | NOT NULL, DEFAULT 'understanding_event' | 對話流程狀態 (例如：`understanding_event`, `waiting_for_location`, `ready_to_submit`) |
| **raw_description** | TEXT | NULL | 里民傳送的原始自然語言描述文字 |
| **address_text** | TEXT | NULL | Agent 抽取或里民輸入的地點文字描述 |
| **latitude** | NUMERIC(10, 7) | NULL | 緯度座標 (透過 LINE GPS 或 Web 地圖選點取得) |
| **longitude** | NUMERIC(10, 7) | NULL | 經度座標 (透過 LINE GPS 或 Web 地圖選點取得) |
| **confidence_score** | NUMERIC(3, 2) | NULL | 地點解析可信度評分 (範圍 0.00 ~ 1.00) |
| **images** | JSONB | NULL, DEFAULT '[]'::jsonb | 暫存圖片網址陣列 (採高效二進位 JSONB) |
| **missing_info** | JSONB | NULL, DEFAULT '[]'::jsonb | 待向里民追問的缺漏欄位清單 (例如：`["location"]`) |
| **created_at** | BIGINT | NOT NULL | 草稿建立時間 (13位數毫秒時間戳) |
| **updated_at** | BIGINT | NOT NULL | 草稿最後更新時間 (13位數毫秒時間戳) |

```sql
-- 建立常用查詢索引，加速對話狀態檢索與高頻輪詢
CREATE INDEX idx_event_drafts_line_user ON event_drafts(line_user_id);
CREATE INDEX idx_event_drafts_status ON event_drafts(status);
```
