# 四上

## 1. `users` (使用者表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **account** | VARCHAR(100) | PRIMARY KEY | 登入帳號 使用者唯一識別碼 只能是英文和數字 |
| **name** | VARCHAR(100) | NOT NULL | 使用者姓名 |
| **is_staff** | BOOLEAN | NOT NULL, DEFAULT FALSE | 是否為社區工作人員（`TRUE`: 工作人員/里長/幹事，`FALSE`: 一般里民） |
| **staff_village** | VARCHAR(100) | NULL | 工作人員授權村里（工作人員必要，且僅能有一個；一般居民為 NULL）|



```sql
CONSTRAINT chk_account_alphanumeric CHECK (account ~ '^[A-Za-z0-9]+$'),
CONSTRAINT chk_staff_village_binding CHECK ((is_staff = TRUE AND staff_village IS NOT NULL AND staff_village <> '') OR (is_staff = FALSE AND staff_village IS NULL))
```

## 2. `categories` (申報類別字典表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 |
| --- | --- | --- | --- |
| **categories_id** | SERIAL | PRIMARY KEY | 唯一識別碼（PostgreSQL 自動遞增整數） |
| **key_name** | VARCHAR(50) | NOT NULL, UNIQUE | 程式用的英文 key (如: dengue) |
| **label** | VARCHAR(100) | NOT NULL | 前端顯示用的中文名稱 (如: 登革熱跡象申報) |
| **color_code** | VARCHAR(10) | NOT NULL | 前端標籤顏色代碼 (如: #FF4552) |
| **require_closing_image** | BOOLEAN NOT NULL | DEFAULT FALSE | 結案時是否強制要求上傳完工證明圖片（TRUE: 必填，FALSE: 選填）|


## 3. `cases` (通報案件表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **cases_id** | BIGINT | PRIMARY KEY | 案件編號（例如：`1717000000011`） |
| **description** | TEXT | NOT NULL | 問題詳細描述 |
| **category_id** | INT | NOT NULL | 申報類別，🔗 **外鍵**：對應 `categories.categories_id` |
| **images** | JSONB | NULL | 申報圖片陣列（存放 GCS 網址或檔名陣列） |
| **status** | VARCHAR(50) | NOT NULL, DEFAULT `'pending'` | 處理狀態（例如：`pending`、`in_progress`、`resolved`） |
| **created_at** | BIGINT | NOT NULL | 案件建立時間（13 位數毫秒時間戳） |
| **updated_at** | BIGINT | NOT NULL | 案件最近更新時間（13 位數毫秒時間戳） |
| **author_account** | VARCHAR(100) | NOT NULL | 發布者帳號，🔗 **外鍵**：對應 `users.account` |
| **assignee_account** | VARCHAR(100) | NULL | 目前負責人帳號（未認領時為 `NULL`），🔗 **外鍵**：對應 `users.account` |
| **villcode** | VARCHAR(18) | NOT NULL | 所屬村里識別碼（依 GPS 反查判定），🔗 **外鍵**：對應 `taiwan_villages.villcode` |
| **address** | TEXT | NOT NULL | 事件發生地點地址 |
| **status_logs** | JSONB | NOT NULL, DEFAULT `'[]'::jsonb` | 處理紀錄（建案及後續操作歷程，JSON 陣列格式） |
| **closing_result** | TEXT | NULL | 結案結果（`status = 'resolved'` 時必填） |
| **closing_images** | JSONB | NULL | 結案佐證照片（依 `categories.require_closing_image` 決定是否必填，JSON 陣列格式） |

**索引與約束條件：**

```sql
-- 索引
PRIMARY KEY (cases_id)
INDEX idx_cases_villcode_status ON cases (villcode, status)

-- 條件約束：已結案時，結案結果不得為空
CONSTRAINT chk_cases_closing_result CHECK (status <> 'resolved' OR (closing_result IS NOT NULL AND closing_result <> ''))

-- 外鍵關聯
FOREIGN KEY (author_account) REFERENCES users(account)
FOREIGN KEY (assignee_account) REFERENCES users(account)
FOREIGN KEY (category_id) REFERENCES categories(categories_id)
FOREIGN KEY (villcode) REFERENCES taiwan_villages(villcode)
```


## 4. `taiwan_villages` (台灣村里界圖表)

| 欄位名稱 | 資料型別 | 屬性 / 預設值 | 說明 / 關聯 |
| --- | --- | --- | --- |
| **gid** | SERIAL (INT) | PRIMARY KEY | 流水號主鍵（`taiwan_villages_gid_seq` 自動遞增） |
| **villcode** | VARCHAR(18) | NULL, UNIQUE | 全台唯一村里代碼（例如：`10016010001`），🔗 **被參照**：`cases.villcode` |
| **countyname** | VARCHAR(12) | NULL | 縣市中文名稱（例如：`澎湖縣`） |
| **townname** | VARCHAR(12) | NULL | 鄉鎮市區中文名稱（例如：`馬公市`） |
| **villname** | VARCHAR(39) | NULL | 村里中文名稱（例如：`光明里`） |
| **villeng** | VARCHAR(39) | NULL | 村里英文名稱 |
| **countyid** | VARCHAR(3) | NULL | 縣市英文代碼（例如：`X`） |
| **countycode** | VARCHAR(8) | NULL | 縣市行政區代碼（例如：`10016`） |
| **townid** | VARCHAR(8) | NULL | 鄉鎮市區英文代碼 |
| **towncode** | VARCHAR(12) | NULL | 鄉鎮市區行政區代碼（例如：`10016010`） |
| **note** | VARCHAR(30) | NULL | 圖資備註（例如無人島嶼或特殊界線說明） |
| **geom** | GEOMETRY(MultiPolygon, 4326) | NULL | 村里多邊形邊界幾何資料（WGS84 經緯度，供 PostGIS `ST_Contains` 反查） |

**索引與關聯：**

```sql
-- 索引與約束
PRIMARY KEY (gid)
UNIQUE CONSTRAINT uq_taiwan_villages_villcode (villcode)
INDEX taiwan_villages_geom_geom_idx ON taiwan_villages USING GIST (geom)

-- 被外鍵參照
REFERENCED BY cases(villcode) CONSTRAINT fk_cases_villcode
```


# 帳號權限

| 物件名稱 | 類型 | `postgres` (管理員) | `ai_user` (應用程式) | `readonly_user` (唯讀) | `PUBLIC` (預設公開) |
| --- | --- | --- | --- | --- | --- |
| **cases** | table | 完整權限 (`arwdDxtm`) | 新增、查詢、修改 (`arw`) | 僅查詢 (`r`) | 無 |
| **categories** | table | 完整權限 (`arwdDxtm`) | 新增、查詢、修改 (`arw`) | 僅查詢 (`r`) | 無 |
| **users** | table | 完整權限 (`arwdDxtm`) | 新增、查詢、修改 (`arw`) | 僅查詢 (`r`) | 無 |
| **taiwan_villages** | table | 完整權限 (`arwdDxtm`) | 僅查詢 (`r`) | 僅查詢 (`r`) | 無 |
| **spatial_ref_sys** | table | 完整權限 (`arwdDxtm`) | 僅查詢 (`r`) | 僅查詢 (`r`) | 僅查詢 (`r`) |
| **geography_columns** | view | 完整權限 (`arwdDxtm`) | 新增、查詢、修改 (`arw`) | 僅查詢 (`r`) | 僅查詢 (`r`) |
| **geometry_columns** | view | 完整權限 (`arwdDxtm`) | 新增、查詢、修改 (`arw`) | 僅查詢 (`r`) | 僅查詢 (`r`) |
| **categories_categories_id_seq** | sequence | 完整權限 (`rwU`) | 查詢、遞增取值 (`rU`) | 僅查詢 (`r`) | 無 |
| **taiwan_villages_gid_seq** | sequence | 完整權限 (`rwU`) | 無 | 僅查詢 (`r`) | 無 |

---

### 權限摘要

* **`postgres`**：資料庫擁有者，具備所有表的完整操作權限（含 `DELETE`、`TRUNCATE` 與結構變更）。
* **`ai_user`**：對業務表（`cases`、`categories`、`users`）具備新增、查詢與修改權限，**無刪除（`d`）與清空（`D`）權限**；對圖資表（`taiwan_villages`）與座標系統表（`spatial_ref_sys`）已收緊為**僅唯讀（`r`）**。
* **`readonly_user`**：對所有資料表、檢視表與序列皆為**嚴格唯讀（`r`）**。
