# 1.摘要
本專題開發「社區小尖兵（Community Helper）」，為一套以村里為單位的行動優先 AI 智慧社區 Web 平台，旨在解決社區仰賴 LINE 溝通所衍生的資訊分散、附件過期及人工負擔等痛點。系統整合 LINE 作為登入與導流媒介，並以後端持久化儲存提供結構化服務。針對一般與高齡居民，平台結合影像分析、語音辨識與定位技術，降低事件申報門檻，同時提供案件進度追蹤、AI 生活助理及在地活動福利查詢。此外，系統為村里工作人員建置分區案件管理功能，涵蓋認領、釋放、進度更新、轉介與結案回報，藉此建立透明且高效率的社區服務閉環。

**關鍵字:智慧社區、人工智慧、多模態輸入、高齡友善、案件管理**

# 2.前言
隨著智慧型手機與即時通訊軟體的普及，台灣多數村里與社區已習慣以 LINE 作為居民與管理人員之間的主要溝通管道，涵蓋公告發布、環境問題通報、活動宣傳及政府福利分享等日常事務。然而，LINE 的核心定位為即時通訊軟體而非專用的社區管理系統，長期使用下逐漸浮現多項結構性問題。首先，各類公告、福利資訊與通報紀錄散落於群組對話與外部網頁中，極易遭新訊息覆蓋而難以檢索；其次，通訊軟體傳送的照片與檔案多具存取期限，一旦過期便無法查閱，影響案件的長期追蹤與歷史留存；此外，現有通報與查詢流程高度仰賴人工文字輸入與重複回覆，不僅加重村里工作人員的行政負擔，對不熟悉鍵盤操作的高齡居民而言更構成明顯的使用門檻。

為解決上述痛點，本專題開發「社區小尖兵（Community Helper）」，建置一套以村、里為基本服務單位的行動優先（Mobile-first）AI 智慧社區 Web 平台。本系統的設計理念並非取代社區既有的 LINE 群組，而是延續居民熟悉的使用習慣，將 LINE 定位為日常溝通、身分登入與服務導流的媒介，並由 Web 平台與後端系統承接結構化的資料管理與持久化儲存，有效克服資訊分散與附件失效的風險。

在核心服務設計上，本平台以「讓居民透過更少的操作完成社區服務」為出發點，特別強化高齡友善體驗。居民在通報社區環境問題時，可結合現場拍照、AI 影像分析、語音辨識與地理位置服務，大幅減少文字輸入並由系統自動判定事件所屬村里；同時，平台亦整合透明化的個人與公開案件進度追蹤、AI 社區生活助理，以及在地活動與福利資訊查詢。針對村里工作人員，系統則依村里授權劃分管理權限，提供涵蓋認領、釋放、進度更新、轉介與結案回報的完整案件管理流程。本專題期盼透過多模態人工智慧與結構化案件管理機制的結合，為基層社區建立一套低門檻、高透明且具永續保存價值的數位服務閉環，進而提升社區治理效率與居民生活品質。
